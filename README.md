# SameShop

Адаптивный демо-интернет-магазин техники на React + Vite.

## Уже работает
- Поиск по названию и категории
- Фильтрация каталога
- Добавление товаров в корзину с подсчётом суммы
- Избранные товары
- Адаптивная вёрстка для телефона и компьютера
- Форма подписки с демонстрационным уведомлением

> Это frontend-демо. Заказы, платежи, авторизация и подписка пока не подключены к серверу.

## Запуск локально

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```
